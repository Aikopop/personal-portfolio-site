# Personal Portfolio Site

Una página web multilingüe con navegación por categorías, panel de inicio de sesión de demostración y personalización de perfil.

## Uso

Abre `index.html` directamente en un navegador o sirve la carpeta con un servidor estático:

```bash
python3 -m http.server 8000
```

Luego visita `http://localhost:8000`.

## Inicio de sesión de demostración

1. Ingresa cualquier correo electrónico.
2. Aparecerá un código aleatorio de seis dígitos en la esquina superior derecha.
3. Copia el código dentro de los 10 segundos y escríbelo en el formulario.
4. Al verificarlo correctamente, accederás al perfil.
